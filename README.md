# 🛒 Shopping List Manager

A beginner-friendly command-line Shopping List Manager built using Python.

## ✨ Features
- Add items to your shopping list
- View all items
- Remove items
- Count total items
- Search for items
- Exit the program

## 🛠️ Technologies Used
- Python 3

## 📚 Concepts Practised
- Variables and user input
- If-elif-else statements
- While loops
- Lists and list methods
- `.append()` and `.remove()`
- `len()` function
- `in` operator

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the Python file:

```bash
python main.py
```
